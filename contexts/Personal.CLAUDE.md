# Personal repositories

Everything under this folder is my own work, and almost all of it is
public open source.

- Never write an account name, a token, a machine name, or a local
  path into any repository here. Other people clone these.
- GitHub is the system of record for everything: issues, pull requests,
  releases, and CI. Use `gh` or the GitHub API with the personal account
  named below. Nothing here uses Azure DevOps.
- Only a person merges a pull request. Open them as drafts, and keep
  the repository's issue current as the work progresses.
- These repositories share a template chain rooted at my `.github`
  repository. Its `AGENTS.md` and `docs/` hold the conventions;
  a repository's own files win over anything here.
